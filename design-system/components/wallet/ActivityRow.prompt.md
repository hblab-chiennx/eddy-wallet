One Recent Activity entry. The whole point is that allowance, spending, loans, interest and lessons all use ONE row shape — glyph tint carries the type, so the feed stays scannable.

```jsx
<ActivityRow type="allowance" title="Weekly allowance" meta="Sunday · from Dad" amount={5} />
<ActivityRow type="spend" title="Comic book" meta="Tue · logged by Mia" amount={4.25} pending />
<ActivityRow type="lesson" title="What is interest?" meta="Finished Monday" points={10} />
```
