Every dollar figure in Eddy Wallet renders through this — never hand-format money.

```jsx
<MoneyAmount value={42.5} size="hero" direction="neutral" />
<MoneyAmount value={-5} size="md" showSign />
```

Always two decimals, always tabular mono so columns line up. Teal = money in, Berry = money out, Ink = a balance (a balance is a fact, not a direction).
